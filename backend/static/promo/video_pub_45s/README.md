## 🎬 GUIDE D'ASSEMBLAGE CAPCUT (30 min)

### Étape 1 — Setup projet
1. Ouvre **CapCut** (mobile ou desktop, gratuit)
2. Nouveau projet → Ratio **9:16 (TikTok/Reels)**
3. Résolution : **1080 × 1920** · FPS : **30**

### Étape 2 — Import assets
1. Importe **tout le dossier** de 24 PNG
2. Importe le **fichier voix-off MP3** (reçu de Fiverr)
3. Dans **CapCut Music Library** → cherche "Corporate Feel Good" ou "Uplifting Acoustic"

### Étape 3 — Timeline (8 pistes)
| Piste | Contenu | Astuce |
|---|---|---|
| **1** Background | Rectangle plein gris #F4F5F7 | Statique 45s |
| **2** Personnage | 7 poses Michel | Change à chaque scène (voir storyboard) |
| **3** Objets | Papiers, iPhone, laser… | Apparaissent avec zoom rapide |
| **4** Flèches vertes | arrow_*.png | Animation "draw on" (dessine à l'écran) |
| **5** Captures d'app | Screenshots MesureChâssis réels | À ajouter par-dessus le téléphone cartoon |
| **6** Voix-off | MP3 Fiverr | Volume **-6dB** |
| **7** Musique | CapCut library | Volume **-18dB** |
| **8** Sons effets | Whoosh, Ding, Cash | CapCut Sound FX gratuits |

### Étape 4 — Animations recommandées (par scène)
- **Scène 1 (Overwhelmed)** : Effet "Shake" fort sur Michel + zoom in visage
- **Scène 2 (Calculating)** : Fade in du chrono avec tic-tac son
- **Scène 3 (Eureka)** : "Pop" ampoule + zoom rapide iPhone
- **Scène 4-6 (Features)** : "Slide-in from right" pour chaque
- **Scène 7 (Cash)** : "Pop-out" billets + son KA-CHING
- **Scène 8 (Transition réelle)** : "Cross-fade" 2 secondes cartoon → photo
- **Scène 9-10 (Photo)** : "Slow zoom-in" doux
- **Scène 11 (CTA)** : "Pulse" sur bouton téléchargement + rebond

### Étape 5 — Sons d'effet (dans CapCut Sound Library gratuit)
- `Woosh 01` — transitions
- `Pop notification` — bulles apparaissent
- `Ding chime` — validations positives
- `Cash register` — scène billets
- `Camera shutter` — photos anti-litige
- `Digital notification` — CTA final

### Étape 6 — Texte overlay
- **Police recommandée** : Poppins Bold ou Montserrat Bold
- **Taille** : 80-100px pour texte principal
- **Couleurs clés** :
  - Rouge urgence : `#E63946` (SCÈNE 1, 2)
  - Vert validation : `#22C55E` (SCÈNE 5, 10)
  - Orange marque : `#F58220` (accents)
  - Blanc contour noir : lisibilité max
- **Animation** : "Typewriter" pour les hooks, "Bounce" pour les CTA

### Étape 7 — Export final
- Format : **MP4 (H.264)**
- Résolution : **1080 × 1920**
- FPS : **30**
- Bitrate : **Élevé (8-12 Mbps)**
- Extension : `mesurechassis_pub_45s_v1.mp4`
