1. Qu'est-ce que MesureChâssis ?

MesureChâssis est une application mobile professionnelle destinée aux menuisiers et entreprises de pose de châssis/fenêtres. Elle remplace le carnet de notes sur les chantiers : prise de mesures guidée (12 formes de baies), génération automatique de fiches techniques PDF prêtes pour la production, gestion d'équipe (commerciaux, techniciens), exports CSV/XML, en 3 langues (français, anglais, néerlandais).

C'est un logiciel par abonnement (SaaS) : les clients paient un abonnement mensuel via Stripe. L'application est (au moment de la rédaction) en cours de publication sur l'App Store (Apple) et Google Play, avec une campagne de recrutement de testeurs et une prospection commerciale en Belgique, France et Luxembourg.

4. Les revenus

Les clients s'abonnent depuis l'application (sauf sur iPhone, conformité Apple) ou via le site. Les tarifs en vigueur sont visibles sur mesurechassis.com (page Tarifs) : formule artisan solo et formule entreprise avec places commerciales/techniciens supplémentaires facturées par siège. L'argent encaissé par Stripe est viré automatiquement sur le compte bancaire relié au compte Stripe.

📊 Pour voir les chiffres en temps réel : se connecter sur dashboard.stripe.com (abonnés actifs, revenus) et sur le tableau de bord admin de l'application (statistiques d'usage).

5. Vous reprenez ? Vos 3 options

Option A — Continuer l'aventure 🚀

  1. Récupérez les accès (enveloppe) et changez tous les mots de passe.
  2. Vérifiez que Railway, Easyhost et Apple Developer sont payés (cartes bancaires à jour).
  3. Connectez-vous sur app.emergent.sh : ouvrez le projet MesureChâssis et écrivez simplement à l'assistant IA « Je reprends le projet de Michel, fais-moi un état des lieux ». Il connaît tout le projet et vous guidera en français.
  4. Alternative classique : engagez un développeur freelance (technologies : React Native/Expo + FastAPI/Python + MongoDB — très répandues, n'importe quel bon freelance peut reprendre).
  5. Répondez aux clients via info@mesurechassis.com.

Option B — Mettre en pause (geler à moindre coût) ⏸️

  1. Gardez absolument : le nom de domaine (Easyhost) et le dépôt GitHub. Coût : ~100 €/an.
  2. Prévenez les clients abonnés par email, remboursez le mois en cours via Stripe.
  3. Suspendez le serveur Railway (plus de frais mensuels).
  4. Tout pourra être relancé plus tard : le code et le domaine sont le patrimoine.

Option C — Vendre 💰

MesureChâssis a de la valeur : un produit fini, multilingue, publié dans les stores, avec un positionnement de niche (menuiserie) et une base de prospects. Acheteurs potentiels :

  • Les éditeurs de logiciels pour la menuiserie (ex. : Elcia, Ramasoft, A+W) — le produit complète leurs gammes ;
  • Un concurrent ou une entreprise de menuiserie ambitieuse qui veut l'outil pour elle ;
  • Les places de marché de revente de SaaS : acquire.com, flippa.com (annonces en anglais).

Faites-vous accompagner par le notaire/comptable pour la cession. Ce qui se vend : le code (GitHub), le domaine, la marque, les comptes stores et la base clients.
