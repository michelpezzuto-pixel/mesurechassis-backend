Si l'écran de l'app est VERT et affiche un compte à rebours "J-X" positif, offrez le café.
📋 Procédure de validation
1
Le client vous présente son écran
Il ouvre l'app MesureChâssis et tape sur "Mes cafés". Un écran vert apparaît avec la mention "1 café vous attend !"
2
Vérifiez le compte à rebours "J-X"
Le badge vert affiche J-1 à J-15. Si le nombre est ≥ 1, la validité est OK. Si J-0 ou "Expiré", refusez poliment.
3
Servez le café ☕
Le client tape le bouton "VALIDATION POMPISTE" — vous saisissez le code PIN de la station (fourni à part). Le jeton est consommé, plus de fraude possible.
✅ / ❌ Comment reconnaître un jeton valide
✅ ACCEPTEZ Écran VERT + badge "J-1" à "J-15" + logo MesureChâssis
❌ REFUSEZ Écran gris, badge "Expiré" ou "J-0", capture d'écran (photo)
