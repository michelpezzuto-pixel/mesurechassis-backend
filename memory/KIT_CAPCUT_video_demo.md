# 🎬 Kit vidéo démo MesureChâssis — CapCut

Storyboard 60 s clé-en-main pour tourner la vidéo de démo qui sera intégrée
sur `mesurechassis.com/demo.html`. À importer directement dans **CapCut**.

---

## 📐 Spécifications techniques

| Paramètre | Valeur |
|---|---|
| **Format prioritaire** | 16:9 (1920×1080) pour le site web |
| **Format secondaire** | 9:16 (1080×1920) pour Reels / Stories / TikTok |
| **Durée cible** | 60 secondes (55-65s max) |
| **FPS** | 30 |
| **Codec export** | H.264 / MP4 |
| **Débit** | 8-12 Mbps (qualité "haute" CapCut) |
| **Audio** | Voix off (VO) + musique de fond -18 dB |

## 🎵 Recommandations musique (banque libre CapCut)

Cherchez dans CapCut → onglet **Audio → Recommandé** ou **Genres → Business/Motivational**.

Mots-clés à taper dans la barre de recherche CapCut :
- `Corporate Uplifting`
- `Startup Growth`
- `Motivational Business`
- `Tech Explainer`

**Éviter** : les musiques trop pop / trop tendues / trop cinématographiques.
**Cible** : rythmique légère, kick discret, montée progressive, outro douce.

**Niveau audio** : gardez la musique à **-18 dB** minimum sous la VO pour que
votre voix reste dominante.

## ✂️ Éléments à ajouter dans CapCut

### Captions (sous-titres burnés)
Activez **Sous-titres automatiques → Français → Style "Bold Center"** dans CapCut,
police *Poppins Bold* ou *Montserrat Black*, taille 60-70, couleur **blanc** avec
**contour noir 4 px**. Toujours en bas au tiers inférieur.

### Transitions
- Entre les plans démo → **Whip / Rush** (rapides)
- Sur les chiffres chocs → **Zoom in + Bounce** (CapCut → Effet → "Punch")
- Sur les fonds noirs → **Fade Black** (0.3 s)

### Overlay logo
Placez le logo MesureChâssis (`/app/site_mesurechassis_final/logo.png`) en **watermark** :
- Position : coin haut-droit
- Opacité : 40 %
- Taille : 60×60 px
- Présent sur toute la vidéo sauf plan 14 (outro plein écran)

## 📤 Intégration sur mesurechassis.com

Une fois la vidéo exportée, 2 options :

### Option A — YouTube (recommandé, chargement le plus rapide)
1. Uploadez la vidéo en *"Non répertoriée"* (visible seulement via le lien)
2. Copiez l'ID (partie après `v=` dans l'URL YouTube)
3. Dans `demo.html`, remplacez le bloc `<div class="video-placeholder">` par :

```html
<iframe src="https://www.youtube.com/embed/VOTRE_VIDEO_ID?rel=0"
        title="Démo MesureChâssis"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
        allowfullscreen></iframe>
```

### Option B — Fichier auto-hébergé
1. Uploadez `demo-mesurechassis.mp4` dans `/app/site_mesurechassis_final/videos/`
2. Créez aussi un `poster.jpg` (image d'aperçu 1920×1080)
3. Dans `demo.html`, remplacez le placeholder par :

```html
<video controls poster="images/demo-poster.jpg" preload="metadata">
    <source src="videos/demo-mesurechassis.mp4" type="video/mp4">
</video>
```
