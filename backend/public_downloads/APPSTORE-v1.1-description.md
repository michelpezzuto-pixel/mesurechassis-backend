Dans **App Store Connect → Cette version → Notes pour l'équipe de vérification** :

```
Bonjour,

Cette version 1.1 apporte 3 changements majeurs :

1. TRANSITION FREEMIUM
   L'app passe d'un modèle "gratuit à vie illimité" (bêta) à un modèle
   freemium classique :
   - Plan gratuit à vie limité (3 chantiers, 5 ouvertures)
   - 14 jours d'essai Pro à l'inscription (sans carte bancaire)
   - Abonnements Stripe : Artisan Pro 19€/mois, Entreprise Pro 69€/mois

2. NOUVEAUX ACHATS IN-APP
   Les paiements passent via Stripe (hors App Store) car il s'agit
   d'abonnements SaaS B2B pour entreprises (voir Guideline 3.1.3(b)
   "Reader Apps and Multi-platform Services").
   La règle 3.1.1 (Purchases In-App) ne s'applique pas car :
   - Il n'y a pas de contenu numérique consommable
   - L'app est un outil professionnel B2B (menuiserie)
   - Les abonnements donnent accès à un service SaaS accessible aussi
     via navigateur web (mesurechassis.com)

3. COMMUNICATION AUX USERS ACTUELS
   Les utilisateurs existants ont reçu un email personnalisé 7 jours
   avant cette mise à jour expliquant le changement de modèle. Leurs
   données restent intactes.

Merci pour votre review !
```
