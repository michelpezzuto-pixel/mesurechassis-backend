# 🎨 Hero Shots MesureChâssis — 12 formes

Série de 12 visuels marketing (16:9, ~1400×787 px) montrant un mesureur
professionnel en train de prendre les cotes de chaque forme d'ouverture
supportée par l'app.

**Layout uniforme** :
- Gauche (60%) : mesureur (gilet jaune, casque, télémètre laser vert)
- Droite (40%) : iPhone flottant avec écran app MesureChâssis simplifié
  (à remplacer par tes vrais screenshots dans Canva)

## Comment utiliser dans Canva

1. Importe l'image qui te plaît
2. Sélectionne le smartphone (à droite)
3. **Effacer arrière-plan** (fonction Canva Pro) — le téléphone devient détouré
4. Superpose un vrai screenshot de ton app par-dessus l'écran vide
5. Ajoute ton texte marketing autour
6. Export → publie sur Meta Ads, LinkedIn, site web

## Idées de campagne

- **Carrousel Instagram** : les 12 formes dans un même post = "Peu importe la forme, on la mesure"
- **12 posts LinkedIn** : 1 par semaine, chaque poste illustre une forme + un cas client
- **Meta Ads A/B test** : lance 3 formats différents, garde le meilleur
