# 🎨 Hero Shots MesureChâssis — Pack Diversité Complet

12 visuels marketing (16:9 HD) — la série reflétant la réalité du BTP en France.

## Distribution

- 👨🏻 **5 hommes blancs** — Trapèze, Plein cintre, Pan coupé, Bow-window, Ovale
- 👩🏻 **2 femmes blanches** — Rectangle, Œil-de-bœuf
- 👨🏾 **2 hommes noirs** — Coulissant levant, Porte de garage
- 👨🏻‍🦱 **2 hommes maghrébins** — Porte d'entrée, Arc surbaissé
- 👨🏻 **1 homme asiatique** — Polygone

## Utilisation stratégique

1. **Carrousel Instagram/LinkedIn** : les 12 en un post = 12 doigts glissés = ×10 temps de visionnage
2. **Landing page** : grille 4×3 sur mesurechassis.com — preuve visuelle
3. **Meta Ads segmentées** : cibler par zone/démographie avec le visuel qui parle le mieux
4. **Canva** : remplace le screenshot du téléphone par ton vrai screen d'app selon le contexte

## Format

- Résolution : ~1400 × 787 px
- Format : PNG haute qualité (~700-800 KB chacun)
- Ratio : 16:9 (parfait Feed FB/LinkedIn — à recadrer 1:1 pour Instagram Feed / 9:16 pour Reels)
